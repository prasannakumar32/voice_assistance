# Gemini Live Voice Assistant

Real-time browser voice assistant using Gemini Live native audio over a
server-side WebSocket proxy.

```
Browser microphone
    │
    ▼
Node.js / Express + WebSocket
    │
  └── Gemini Live API       → streamed PCM audio in/out
```

## Setup

```bash
npm install
cp .env.example .env
# then edit .env and add your real GEMINI_API_KEY
```

Get an API key from Google AI Studio.

## Run

```bash
npm start
```

Server runs on `http://localhost:5000` by default (change `PORT` in `.env`).

## Live connection

The frontend connects to `ws://localhost:5000/api/voice-live` (or `wss://` over
HTTPS). It sends 16-bit PCM audio at 16 kHz and receives 24 kHz PCM audio from
Gemini Live.

The API key never reaches the browser. The server creates one stateful Live API
session per connected browser and closes it when the browser disconnects.

## Notes

- The API key stays server-side only (`.env`), never in the React frontend.
- `GEMINI_CONVERSATIONAL_MODEL` controls the Live API model and defaults to
  `gemini-2.5-flash-native-audio-latest`.
- Voice output is generated by the Live model in the same session.

The Gemini API free tier requires an API key from Google AI Studio and has usage
limits. The consumer Gemini app's free Live mode is separate and cannot be
embedded in this application.
